# just sing

A K-pop karaoke web app built at SwampHacks XII!!! Pick a song, sing along with the instrumental, watch your live pitch drawn over the target melody with synced Korean lyrics, romanization, and English translation, then get an AI-graded score for pitch, timing, and pronunciation with per-line feedback and a short coaching note. ♪( ´θ｀)ノ
